# Wang Yangming Former Residence: Web3D Cultural Interactive System

## Overview

This project is a Web3D cultural experience centered on the former residence of Wang Yangming. It uses dynamic storytelling to help visitors explore cultural content, was developed with an AIGC-assisted workflow, and includes work to optimize WebGL performance.

## Experience

- Explore a Web3D cultural environment.
- Follow a dynamically presented narrative.
- View the deployed experience: [Open the Web3D demo](https://pub-998a4a31341540b9a406929178f5e2f1.r2.dev/jingsai/index.html).

## Technology and Development

- Web3D interactive experience.
- AIGC-assisted development workflow.
- WebGL performance optimization.

# 王阳明故居 Web3D 文化交互系统

本项目以王阳明故居为主题，构建 Web3D 文化体验。系统通过动态叙事呈现文化内容，采用 AIGC 辅助开发流程，并对 WebGL 性能进行了优化。
